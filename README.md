# ระบบหาปริมาณความเสียหายโครงสร้างจากภาพถ่าย (Crack-AI)

วัดรอยร้าว พื้นที่ผิวคอนกรีตเสียหาย และเหล็กเสริม จากภาพถ่ายหน้างาน คำนวณเป็นค่าจริง (cm, ตร.ซม.) จากวัตถุอ้างอิงในภาพ
มีตัวช่วยตรวจจับด้วย AI (YOLO) ที่คุณเทรนเองจากงานที่ตรวจทานแล้ว และส่งออกรายงาน Excel

เวอร์ชันปัจจุบัน **2.0.0** ดูสิ่งที่เปลี่ยนใน [CHANGELOG.md](CHANGELOG.md) หรือกด "มีอะไรใหม่" ที่ท้ายหน้าเว็บ

## ใช้งานได้ 2 แบบ

| | หน้าเว็บอย่างเดียว | หน้าเว็บ + เซิร์ฟเวอร์ AI |
|---|---|---|
| ติดตั้ง | ไม่ต้อง เปิดจาก GitHub Pages | ติดตั้ง Python บนเครื่องที่มีการ์ดจอ |
| วัดด้วยมือ, Excel, คลังงาน | ได้ | ได้ |
| ตรวจจับด้วย AI | ไม่ได้ | ได้ |
| เทรนโมเดล | ส่งออกชุดข้อมูลไปเทรนที่อื่นได้ | ได้ ในหน้าเว็บ |

## ข้อมูลถูกเก็บไว้ที่ไหน

| ข้อมูล | ที่เก็บ | หมายเหตุ |
|---|---|---|
| คลังงานตรวจสอบ (ภาพ + ผลการวัดทุกโปรเจกต์) | เบราว์เซอร์ของเครื่องนั้น (IndexedDB) | ไม่ถูกส่งขึ้นอินเทอร์เน็ต กด "สำรองคลัง" เป็นระยะ |
| ชุดข้อมูลสำหรับเทรน | `workspace/dataset/` บนเครื่องที่รันเซิร์ฟเวอร์ | มาจากคลัง (เฉพาะที่เปิด "ใช้เทรน") หรือจากไฟล์ zip ที่อัปโหลด |
| โมเดลที่เทรนแล้ว | `workspace/runs/<รอบ>/weights/best.pt` | |
| โมเดลตั้งต้นที่ดาวน์โหลด | `workspace/weights/` | |
| ไฟล์โปรเจกต์ .json / รายงาน .xlsx | โฟลเดอร์ดาวน์โหลดของคุณ | |

โฟลเดอร์ `workspace/` อยู่ใน `.gitignore` แล้ว ภาพของหน่วยงานจะไม่ถูกส่งขึ้น GitHub โดยไม่ตั้งใจ

### คลังงานตรวจสอบทำงานอย่างไร

1. เมื่อวัดหรือแก้ไขรายการในภาพใด ระบบเก็บโปรเจกต์นั้นเข้าคลังให้อัตโนมัติ (ปิดได้ในหน้าคลัง) ภาพเดิมเปิดซ้ำจะรวมเป็นโปรเจกต์เดียว ไม่เกิดซ้ำ
2. แต่ละโปรเจกต์มีสวิตช์ **ใช้เทรน** ค่าเริ่มต้นเปิดเฉพาะงานที่วัดด้วยมือล้วน ถ้ามีผลจาก AI ระบบจะถามยืนยันว่าตรวจทานแล้วก่อน
3. ส่งเข้าชุดเทรนบนเซิร์ฟเวอร์ด้วยปุ่มเดียว ส่งซ้ำได้ (ส่งเฉพาะที่เปลี่ยน) ปิดสวิตช์แล้วส่งอีกครั้ง ภาพจะถูกนำออกจากชุดเทรน
4. ไม่มีเซิร์ฟเวอร์ก็กด "ดาวน์โหลดชุดข้อมูล YOLO" แล้วนำ zip ไปอัปโหลดในหน้าเทรนบนเครื่องอื่นได้

## เผยแพร่หน้าเว็บบน GitHub Pages

1. สร้าง repository แล้ว push ไฟล์ทั้งหมดขึ้น branch `main`
2. ที่ repo ไปที่ **Settings > Pages > Build and deployment > Source** เลือก **GitHub Actions**
3. ทุกครั้งที่ push ไฟล์ `.github/workflows/pages.yml` จะเผยแพร่เฉพาะไฟล์หน้าเว็บ (ไม่รวม `server/`)
4. หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

> ถ้า repo เป็น private ต้องใช้ GitHub แบบเสียเงินจึงจะเปิด Pages ได้ และหน้า Pages จะเป็นสาธารณะเสมอ แต่ข้อมูลงานของคุณอยู่ในเบราว์เซอร์/เครื่องของคุณ ไม่ได้อยู่บนหน้าเว็บ

## ติดตั้งเซิร์ฟเวอร์ AI

ต้องมี Python 3.10 ถึง 3.12

**Windows:** ดับเบิลคลิก `start_windows.bat` ครั้งแรกจะติดตั้ง PyTorch (CUDA 12.8) และไลบรารีอื่นประมาณ 3 ถึง 4 GB จากนั้นเบราว์เซอร์จะเปิด `http://127.0.0.1:8765`

**macOS / Linux:** `./start_mac_linux.sh` (Mac รุ่น Apple Silicon ใช้ GPU ผ่าน MPS)

ติดตั้งเองแบบละเอียด:
```bash
python -m venv .venv
.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r server/requirements.txt
python server/server.py
```

### ใช้หน้าเว็บบน GitHub Pages กับเซิร์ฟเวอร์ในเครื่อง

แก้ `server/config.json` ใส่ origin ของหน้าเว็บ (ไม่ต้องมีชื่อ repo ต่อท้าย) แล้วเปิดเซิร์ฟเวอร์ใหม่

```json
{ "host": "127.0.0.1", "port": 8765, "allowed_origins": ["https://ชื่อผู้ใช้.github.io"] }
```

แนะนำ Chrome หรือ Edge เมื่อเบราว์เซอร์ถามสิทธิ์ "เข้าถึงอุปกรณ์ในเครือข่ายในเครื่อง" ให้กดอนุญาต
ถ้าใช้ไม่ได้ ให้เปิด `http://127.0.0.1:8765` ตรงๆ ซึ่งเป็นหน้าเว็บเดียวกันที่เซิร์ฟเวอร์เสิร์ฟให้

## หมายเหตุเรื่องการ์ดจอ

- RTX 50 series (เช่น 5070 Ti) ต้องใช้ PyTorch ที่สร้างสำหรับ CUDA 12.8 ขึ้นไป (สคริปต์ติดตั้งให้แล้ว)
- Windows เทรนหลายการ์ดพร้อมกันไม่ได้ ให้เลือกการ์ดใดการ์ดหนึ่งในหน้าตั้งค่าการเทรน
- ถ้าเกิด out of memory ให้ลด batch, ลดขนาดภาพ หรือเลือกรุ่นโมเดลเล็กลง

## ลำดับการทำงานที่แนะนำ

1. วัดด้วยมือในภาพจริงสัก 100 ถึง 300 ภาพต่อคลาส (หรือนำเข้าชุดข้อมูล YOLO ที่มีอยู่)
2. เปิดคลังงาน เลือก "ใช้เทรน" แล้วกด "ส่งเข้าชุดเทรนบนเซิร์ฟเวอร์"
3. เปิด "เทรนโมเดล" เลือกระดับ "มาตรฐาน" แล้วกดเริ่ม
4. เทรนเสร็จ กด "ใช้โมเดลนี้ตรวจจับ"
5. ภาพใหม่: กดตรวจจับ ตรวจทาน ลบรายการที่ผิด แล้วเปิด "ใช้เทรน" ให้ภาพนั้นด้วย โมเดลจะดีขึ้นทุกรอบ

ความกว้างรอยร้าวที่ AI ประมาณจากภาพเป็นค่าโดยประมาณเท่านั้น ควรวัดจริงด้วย crack gauge สำหรับงานประเมิน

## โครงสร้างไฟล์

```
index.html, app.js        หน้าเว็บและการวัด/ตรวจจับ/หน้าต่างเทรน
library.js                คลังงานตรวจสอบ
changelog.js              ประวัติเวอร์ชัน (หน้าต่าง "มีอะไรใหม่")
vendor/                   ไลบรารีและฟอนต์ (ทำงานออฟไลน์ได้)
assets/                   วางโลโก้หน่วยงาน logo.png
server/                   เซิร์ฟเวอร์ AI (server.py, trainer.py, config.json)
start_windows.bat, start_mac_linux.sh
workspace/                สร้างอัตโนมัติ: ชุดข้อมูลและโมเดล (ไม่ขึ้น GitHub)
```

## ความปลอดภัย

- เซิร์ฟเวอร์รับการเชื่อมต่อจากเครื่องตัวเองเท่านั้น (127.0.0.1)
- คำสั่งที่เปลี่ยนข้อมูลต้องมาจากหน้าเว็บในเครื่องหรือ origin ที่ระบุใน `config.json` เว็บอื่นสั่งงานแทนคุณไม่ได้
- ไฟล์ zip ที่อัปโหลดถูกตรวจกันการเขียนไฟล์ออกนอกโฟลเดอร์
